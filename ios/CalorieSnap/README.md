# Calorie Snap

אפליקציית iOS פשוטה למעקב אחרי צריכת קלוריות יומית המוגבלת ל-1800 קלוריות.

## יכולות מרכזיות
- צילום מזון באמצעות המצלמה המובנית במכשיר.
- זיהוי אוטומטי והערכת קלוריות בעזרת `Vision` ונתוני קלוריות מובנים.
- סיכום קלורי יומי שמתאפס בכל יום בשעה 06:00.
- התראות Push כאשר עוברים את היעד היומי.
- ממשק מינימליסטי ב- SwiftUI עם כפתורים גדולים וטיפוגרפיה ברורה.

## דרישות
- Xcode 14 ומעלה.
- iOS 16 ומעלה (בשל שימוש ב- `VNClassifyImageRequest`).

## הפעלה
1. פתח את התיקייה `ios/CalorieSnap` ב- Xcode בתור פרויקט SwiftUI חדש.
2. ודא שלאפליקציה יש הרשאות מצלמה והתראות בעת ההפעלה.
3. לחץ על הכפתור "צלם ארוחה חדשה" כדי לצלם מזון ולהוסיף אותו ליומן.
4. מחק רשומות באמצעות החלקה שמאלה ברשימה.

> **הערה:** מנגנון הערכת הקלוריות הוא דוגמה בסיסית המתבססת על מודל הסיווג הכללי של Apple. מומלץ להחליף את טבלת הקלוריות או להרחיבה לפי צרכים תזונתיים ספציפיים.
